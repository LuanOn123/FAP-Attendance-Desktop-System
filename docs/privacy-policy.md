# Privacy Policy - FAP Attendance Connector

**Effective Date:** 2026-09-18

This Privacy Policy describes how the **FAP Attendance Connector** ("the Extension") collects, uses, and shares information when you use it.

## 1. What data is processed
The Extension reads attendance-related data ONLY from the FAP attendance page currently opened by the user in their active browser tab. The processed data includes:
- Course and Class information
- Session details (date, slot, room)
- Student roster information (student code, full name, email, and avatar image, if available on the page)

## 2. Why it is processed
This data is extracted for the sole purpose of importing the student attendance list into the user's locally running **FAP Attendance Desktop System**, enabling offline/local QR code-based attendance.

## 3. Where it is sent
The extracted attendance information is transmitted ONLY to the user's locally running FAP Attendance Desktop Application through `localhost` (127.0.0.1). 
- **The extension does NOT send student information to external cloud servers.**
- **The extension does NOT use third-party analytics (e.g., Google Analytics, Firebase) to track student data.**

## 4. Whether it is stored
The Extension itself does not store any FAP or student data persistently in the browser. It acts purely as a temporary bridge to transfer data from the DOM to the local Desktop App.

## 5. Third-party sharing
We do not sell, trade, or otherwise transfer any processed information to outside parties. The extension does not sell user information and does not use student data for advertising.

## 6. Authentication data
- The extension **does not** collect FAP passwords.
- The extension **does not** access or reuse FAP authentication tokens or cookies.
- The extension **does not** access browsing history outside of the active FAP tab.

## 7. User controls
You can uninstall the Extension at any time from your browser's extension management page. Once uninstalled, the extension will no longer be able to read any FAP pages or communicate with your local Desktop App.

## 8. Contact
If you have any questions or suggestions regarding this Privacy Policy, please contact the developer at [developer@example.com] or via the support tab on the Chrome Web Store.
